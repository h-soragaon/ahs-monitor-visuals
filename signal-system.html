System Design v1

Signal

A closed-loop system that detects when students aren't learning, diagnoses why, recommends what to do, and tracks whether it worked. Built on Andy's TimeBack framework. Operated by Hari as Campus Learning Controller.

"Aggregate scores tell you THAT something is broken. Question-level results tell you WHY." — Andy Montgomery, TimeBack Closed-Loop System

Operating System

The OODA Cycle

Every student, every course, every cycle gets run through Observe → Orient → Decide → Act. Each test tightens the loop.

O

Observe

Pull test results, daily metrics, activity data from all pipelines

→
O

Orient

What do they know? What don't they? Is it motivation, placement, or curriculum?

→
D

Decide

Look up playbook. Generate recommendation. Route to owner.

→
A

Act

DRI executes intervention. System tracks action + outcome.

↻ Each test tightens the loop. Nested cycles run at different speeds.

Orient Phase

The Diagnosis Engine

Andy's root cause tree as a deterministic decision flow. Check signal first, then motivation, then placement, then curriculum. Ordering matters.

Sufficient
Signal?

PROCESS FAILURE

"We can't grade ourselves on this student." Not enough data to diagnose. 29 of 105 AP sittings in May 2026 fell here. Andy: "Our problem, not the student's."

Owner: Hari
Get data. Assign practice test. Check enrollment.
On
Track?

ON TRACK

Score ≥ target, completion on pace, trend not declining. 36 of 105 AP sittings projected a 5. No action needed — monitor next cycle.

Owner: System
Auto-monitor. No human action.
Putting
In Time?

MOTIVATION

Low minutes, high inactivity, zero XP. The student isn't showing up. Andy: "Students at 120+ XP still failing need different intervention than encouragement." Carl Hendrick: "94% of 179 intervention courses unstarted."

Owner: Hari (direct)
Accountability + schedule structure via guide.
Right
Level?

PLACEMENT

High effort + low/declining scores = wrong material. Andy: "Base course is the only intervention that doesn't require knowing what's wrong." Becky Allen: Find the "jewels in the curriculum" — the concepts whose mastery reorganizes the subject.

Owner: Hari (direct)
Check working grade (HMG+1). Assign base course.
Content
Teaching?

CURRICULUM

Adequate effort, adequate time, still failing. The content isn't doing its job. If multiple students show the same pattern on the same unit — it's the content, not them.

Owner: Subject DRI
Route with data package. Track DRI response.

Decide Phase

Intervention Playbooks

Each diagnosis maps to a playbook grounded in specific brainlift knowledge. Not generic advice — specific actions from the team's own expertise.

M
Motivation Playbook
1
Awareness Check
Does the student know they're behind? Send data snapshot to guide.
2
Structure Intervention
Establish daily learning block. Quantify: "X min/day for Y days to reach target."
3
Accountability Conversation
Acknowledge wins, then make clear they don't substitute for the work.
Andy BrainLift + Adam's AP CSA insights
4
Escalation
If no change → escalate to Andy with intervention timeline.
P
Placement Playbook
1
Verify Working Grade
Andy's formula: working_grade = highest_mastered_grade + 1. Green if match, yellow if mismatch.
Andy BrainLift: TimeBack Closed-Loop
2
Check Prerequisites
Identify "jewels in the curriculum" — small number of concepts whose mastery reorganizes the subject.
Becky Allen: Knowledge Demand Typology
3
Assign Base Course
"The only intervention that doesn't require knowing what's wrong." Covers invisible gaps.
Andy BrainLift
4
Monitor Response
If improvement → confirmed. If no change → escalate to curriculum.
C
Curriculum Playbook
1
Package Data for DRI
Completion %, accuracy (MCQ/FRQ), trend, time invested, weak areas, cohort pattern.
2
Route to Subject DRI
Adam (Science), Peter (Social Studies), Seb (Math), Ben (Lang/Lit).
3
Track DRI Response
Did they respond? What action was taken? Log it.
4
Verify Outcome
Next cycle: did the student improve? If not → re-diagnose.
!
Process Failure Playbook
1
Identify What's Missing
No practice test? No activity data? No course mapping?
2
Classify the Gap
Never enrolled (planning), enrolled but inactive (motivation), active but no assessments (assessment gap).
3
Close the Gap This Cycle
Every student should have sufficient signal by next cycle. This is our problem, not the student's.
