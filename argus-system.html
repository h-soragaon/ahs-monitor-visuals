Language

Vocabulary

Six terms. No others needed.
Phase
What the student is working toward. Defines the rules. Each phase has its own signals, thresholds, data.
Grain
The unit of analysis. Phase-specific. student × subject, student × exam, student × course.
Signal
What's happening NOW. A named state derived from data. Per grain. Deterministic.
Forecast
Where they'll be IF nothing changes. Gap to target. Simple math, never guesses.
Action
What the operator should do. Determined by signal + forecast. Three tiers: auto, notify, recommend.
Cycle
When the system runs. Weekly (primary), daily (crunch), monthly (patterns).

Gate

Signal Sufficiency

Before computing any signal: do we have enough data? This check runs first, every phase, every grain.
Sufficient
Have progress data AND effort evidence. Can detect on/off track. Can diagnose WHY.
→ Full signal computation runs.
Partial
Have progress data but missing engagement. Can detect on/off track. CANNOT determine why.
→ Signal fires with confidence: low.
Insufficient
No data at all. Can't assess anything. System is blind to this grain.
→ Signal = NO_DATA / no_signal. Process failure.
Sufficiency is non-negotiable. Argus never guesses. If the data isn't there, it says so — loudly. An insufficient grain appears in the CRITICAL section of the report. Blind spots are treated as seriously as off-track students.

Progress data tells you IF they're on track. Effort evidence tells you WHY they're off track. Without effort data, you can flag a problem but can't route it to the right owner.
Projection

Forecast

Will they hit the target if nothing changes? Simple math. Never guesses.
Static Gap (AP, SAT)
GAP = TARGET − CURRENT
AP: target = 4, current = predicted score
SAT: target = 1500/1350, current = latest practice
Gap ≤ 0 → on target. Gap > 0 → intervention needed.
Pacing Math (Mastery, Credits)
NEEDED / DAY > GOAL / DAY → behind
Credits: XP remaining ÷ days remaining vs. daily goal
Mastery: grades remaining ÷ days ÷ 14 days/grade
Ratio ≤ 1.0 → on pace. Ratio > 1.5 → critical.
