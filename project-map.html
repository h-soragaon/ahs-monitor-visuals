An educational data warehouse that tracks student learning across many courseware platforms. Data flows left-to-right: external sources (the edges) → platform ingestion pipelines → a central warehouse (the single source of truth) → student-lifecycle phases → consumption surfaces. Everything is file-based CSV; promotion to production is gated on QC.
